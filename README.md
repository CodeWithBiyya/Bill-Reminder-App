# 💳 Bill Reminder App

Bill Reminder is an Android application that helps users manage recurring bills and avoid late payments. It provides reminders, bill tracking, and an easy-to-use interface.

## ✨ Features

- Add Bills
- Edit Bills
- Delete Bills
- Monthly Bill Tracking
- Payment Status
- Due Date Notifications
- AdMob Integration
- Firebase Analytics
- Material Design UI

## 🛠️ Tech Stack

- Kotlin
- Android SDK
- XML
- SQLite / Room
- AdMob
- Firebase Analytics
- RecyclerView
